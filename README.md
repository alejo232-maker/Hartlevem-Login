# Hartlevem-Login

Sistema de autenticación para Termux.

## Características

- Login con usuario y contraseña
- Contraseña protegida con hash SHA-256
- Bloqueo por intentos fallidos
- Tema hacker
- Instalación automática

## Instalación

```bash
git clone https://github.com/alejo232-maker/Hartlevem-Login.git
cd Hartlevem-Login
bash install.sh
```
